# 🗄️ Banco de Dados & Modelagem - Atividades Acadêmicas

![Status](https://img.shields.io/badge/Status-Concluído-Green)

Este repositório foi criado para centralizar meus estudos e atividades práticas na área de Banco de Dados. Ele armazena o progresso de scripts SQL, modelagens de diagramas e exercícios distribuídos ao longo do curso de **Análise e Desenvolvimento de Sistemas**.

## 🚀 Foco e Aprendizados

As atividades aqui contidas refletem a aplicação teórica e prática de conceitos fundamentais para a gestão de dados:

- 🏗️ **Modelagem de Dados**: Criação e análise de Diagramas Entidade-Relacionamento (DER) para estruturação lógica de sistemas.
- ⌨️ **Scripts SQL**: Desenvolvimento de consultas e comandos utilizando linguagens DDL (Data Definition Language) e DML (Data Manipulation Language).
- 📐 **Padronização**: Aplicação de regras de normalização para garantir a integridade e eficiência do banco de dados.

## 🛠️ Tecnologias e Ferramentas

Para a realização e execução destas atividades, utilizo:

- **Ferramenta de Desenvolvimento**: Oracle SQL Developer (utilizado em ambiente de aula).
- **Linguagem**: SQL (Structured Query Language).
- **SGBDs**: Motores de banco de dados aplicados em aula para execução de scripts.
- **Modelagem**: Ferramentas de design para criação de esquemas lógicos e conceituais.

## 🎓 Contexto Acadêmico

Os projetos e scripts presentes neste repositório fazem parte da grade curricular da **Fatec Sorocaba**, servindo como um portfólio de evolução técnica em engenharia de dados.
